# Work order — S-06.02.32 the connect form offers limit presets

## ID
S-06.02.32. Size S. Frontend only; the API already accepts 0 (`S-06.02.30`).

## DESIGN
In `frontend/src/pages/Connectors.tsx`, the two number inputs become a select
plus, for "Custom", a number input:
- Daily calls: Provider's own limit (0) · 50 · 200 · 1,000 · Custom…
- Daily spend (USD): No cap (0) · $1 · $5 · $20 · Custom…
A saved value that matches a preset shows that preset; any other shows Custom
with the number. What is posted is the number, exactly as today. The presets
live in one exported constant so a test can hold them.

## TEST (write first, watch it fail)
In `frontend/src/components.test.tsx`: the form renders both selects with the
presets; picking Custom reveals the number input; a saved 200 selects "200";
a saved 37 shows Custom with 37.

## DONE WHEN
Tests and build pass, and a real browser connect with a preset posts that
number.
