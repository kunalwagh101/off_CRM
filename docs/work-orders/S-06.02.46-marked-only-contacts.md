# S-06.02.46 — Review only checked contacts, without losing their saved selection

**Owner:** CRM engineer. **Branch:** develop. **Status:** IN_REVIEW.

## Gap
Contact rows already have persistent `checkbox` and a one-row edit endpoint, but the Contacts UI could not show marked records alone.

## Acceptance
- A labelled Marked only filter returns checked campaign memberships through an SQL predicate (`cc.checkbox = 1`), and remains correct with search, category, variant and status.
- The filter is applied *before* limit/offset and count, not client-side on the first 100 items. All marked contacts across 500+ rows are reachable.
- Checking/unchecking affects only that campaign contact; the visible list refreshes, with page correction after the count shrinks.
- Export applies the same filter: no accidental inclusion of unselected campaign contacts.
- No destructive mass change or implicit send is introduced.

## Code and tests
`offsetx_apollo_builder/outreach/store.py`, `offsetx_apollo_builder/api/app.py`, `frontend/src/pages/Contacts.tsx`, focused Python and Vitest regressions.
