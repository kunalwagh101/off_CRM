# Work order — S-06.02.33 trust is the owner's to change, per provider and per model

## ID
S-06.02.33. Decisions `DD-64` is keys; this is `DD-65`. Size M.

## RULE (DD-65)
effective tier of a model =
1. the model's own override, if set; else
2. the provider's override, but never above the model's origin cap; else
3. the derived tier (provider tier, capped by the model's origin).
Lowering needs nothing. Any setting above the default needs a typed reason,
stored with who and when. No trust setting opens the mailbox: received mail
reaches a model only after the separate unlock phrase (rule 5).
