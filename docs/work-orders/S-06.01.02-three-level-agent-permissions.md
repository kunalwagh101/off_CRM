# S-06.01.02 — Three-level agent permissions

**Feature:** F-06.01 team permissions and operations. **Status: IN_REVIEW, not DONE.** `develop` only.

## Outcome
The install token configures an authenticated workspace's default mode and named browser tool modes (the ten-verb closed vocabulary). A browser agent checks policy before touching the page; blocked actions are not executed. A live attended chat can carry temporary grants without writing those grants into the persistent workspace record.

## API and persistence
- `GET /api/v1/agent-permissions`: authenticated current workspace's effective global/per-tool settings; install token may query `?workspace_id=...`.
- `PUT /api/v1/agent-permissions`: install-token-only; exact JSON `{"global_mode":"allow|ask|deny","tool_rules":{"click":"ask"}}`. Optional validated workspace query for a registered workspace. Malformed/unrecognised tools and modes are rejected, previous policy preserved.
- Existing `WorkspaceAISettingsStore.save` is the only persistence entry point. It uses hosted DB with `OFFSETX_DATABASE_URL` and local root otherwise, with existing restart/connection behaviour; no schema migration.
- Default `allow` maintains existing agents, but `global_mode=deny` is not overridable. Individual tools may be `allow`, `ask`, `deny`. A memory-only `ChatPermissionGrants` expires when closed or within one hour, and only changes `ask` to `allow`, never `deny`.

## TDD acceptance
- Owner authenticates, saves policy, sees it after app restart; unauthorized or non-owner cannot change it, invalid tool/mode does not change stored policy.
- For model-selected `click`, deny returns `permission_denied`, ask returns `needs_permission`; both report an action-free trace entry and never touch the browser. Cached `read` also checks policy.
- With explicit chat grant, only that allowed action passes a per-tool `ask`. Expired/closed grants do not persist or elevate denial.
- Unattended scheduled routine must enforce the initial `goto` **before** browser subprocess and network navigation; tenant's policy is loaded from its own workspace.
- Existing ten browser verbs, policy preflight, AI egress wall, and all SQLite/PostgreSQL regressions remain green.
