## 2026-11-24 — D-520, actual Chromium failed-logout and replay gate PASS

The previous React `logout()` executed `setToken("")` and `setAuth(authenticated=false)` in `finally` even when revocation failed. That could falsely show a sign-out while a stolen bearer cookie remained usable. The fix catches revocation errors, preserves authenticated UI and shows an accessible retry warning; it clears browser auth only after successful server confirmation.
