## Acceptance and gates

- Given a captured quote containing a different sign, decimal precision or magnitude, when an observed numeric claim is verified, then it is **unsupported** even if the quote exists verbatim in the captured page.
- Given matching textual numeric evidence, when the verifier checks it, then it remains supported; ordinary non-numeric values retain existing conservative matching/negation behaviour.
- Given a model-produced derived total without verified arithmetic, when it is presented as observed proof, then it must not be labelled supported by text-span matching.
