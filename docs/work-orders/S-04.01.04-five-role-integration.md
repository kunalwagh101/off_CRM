# S-04.01.04 — five agents reuse the existing product engines

Feature F-04.01. State: BACKLOG, build-ahead only. Branch: develop.
Dependencies: S-04.01.01 and S-04.01.03 not accepted DONE.

## User story

An install owner can explicitly provision five named companion profiles for a
workspace. Subsequent role calls must operate through the existing code and
respect every review, workspace, budget, approval and egress rule. No prompt may
create its own tool or skip human approval.

## Built source slice (2026-11-05)

Module agent/role_team.py contains a closed five-role dispatch table:

- Scout reads its workspace's existing observed trend topics. No login, crawl
  or generation is triggered by the role dispatch.
- Maker uses VideoEditorEngine.direct_and_assemble with its existing director
  and assembly validation. The original engine queues the result for review.
- Poster uses TrendPipeline.draft on already approved workspace-owned image
  assets. Draft posts are never approved or published by this role.
- Analyst reads DistributionEngine.progress and generator_performance.
- Director uses GtmService.draft_plan. It never applies or activates campaigns.

Owner-only endpoints POST /api/v1/agent-team/provision and
POST /api/v1/agent-team/execute. Both use request-authenticated workspace; the
second rejects a role not provisioned or currently disabled. Pydantic validates
bounded role fields. Provisioning is idempotent and preserves owner-written
profile modifications; it does not add executable tool grants.

A05 source review found TrendPipeline.draft and topic-history lookups omitted
workspace predicates. Source fixes at d65384b and d7f4bee restrict images,
drafted posts, topic history and cooldowns to the workspace. A focused
two-workspace regression was added to tests/test_pipeline.py.

Profiles and procedures now use hosted SQL when OFFSETX_DATABASE_URL is set,
instead of the disposable local ai_tools SQLite database; the executable
ToolRegistry is still local. Data portability and privacy erasure remain open
under S-06.03.06.
