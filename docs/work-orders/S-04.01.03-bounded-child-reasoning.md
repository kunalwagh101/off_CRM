## Implemented source slice (2026-11-05)

Existing CompanionRegistry profiles are reused. A new delegate_once operation
resolves one parent and one to three explicitly selected child companions in
the same authenticated workspace. Every instruction and child goal is bounded
and validated BEFORE making a model call. Child calls pass through the single
EgressBroker using campaign data classification. Children have no executable
tool call, browser action or publishing permission in this operation. The
parent receives the child result strings, not private child prompts or
transcripts, and synthesises an owner-visible summary.

The existing owner-authenticated API exposes
POST /api/v1/companions/{companion_id}/delegate with a strict list of goals
and child companion IDs. Cross-workspace, disabled, duplicate, self-delegation,
fan-out over three and nonzero nested depth are refused.
