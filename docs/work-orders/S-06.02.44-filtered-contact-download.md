# S-06.02.44 — Export the filtered contact list across every page

**Owner:** senior CRM/backend engineer. **Branch:** develop. **Status:** IN_REVIEW, full suite/live verification outstanding.

## Gap and existing design
The existing `/campaigns/{id}/export?format=csv|xlsx` exports a broad campaign report to a persistent file and is retained unchanged. Contacts UI could not download exactly its active filtered list, and pagination has no all-pages download. No additional external connector is needed.

## Acceptance
- The authenticated user can download CSV of all matching contacts, not only the current 100-item UI page.
- Export includes name, email, company, role, category, route, status, A/B variant, marked flag, send count and public research source — *not* internal notes, email bodies or secrets.
- Dangerous spreadsheet cells remain text, with UTF-8 BOM for spreadsheet compatibility.
- Export is generated in memory (no extra durable file on a wiped Render disk); response is an attachment and is non-cacheable.
- Max 50,000 rows is explicit: oversize and concurrent changes are refused with a reason, never silently truncated.
- The unchanged full-campaign reporting/export remains available.
