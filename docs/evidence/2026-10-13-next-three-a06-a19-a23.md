## A19 — Spreadsheet injection (D-272)

With an apostrophe before dangerous strings, the analogous workbook cell type became `s` (text) and numeric cells stayed numeric. **This only proves the isolated conversion logic, not the repository pipeline.** Added `spreadsheet_safe_cell/frame`, applied to human-readable CSV/XLSX reports, normalized input/manifest reports, and external attempt-ledger snapshots. Raw contact data, JSONL and persistent dedupe/credit state CSV files were deliberately not altered; changing their bytes would break lookup integrity. Regression in `tests/test_spreadsheet_exports.py` checks actual CSV cells, workbook type, and source preservation. Full pipeline/tests and Excel/LibreOffice acceptance **unrun**. Previously generated export spreadsheets need re-export before sharing.

## A06 — Logout revocation (D-273)
Source reproduction: the real API's logout only deleted `SESSION_COOKIE`; `WorkspaceAuthStore.verify` still accepted a copied signed value if not expired. Added a forward-only `USER_STEPS` migration creating `workspace_revoked_sessions` in PostgreSQL; a matching `CREATE TABLE IF NOT EXISTS` is in SQLite schema. `revoke()` hashes the token, inserts its digest and expiry, and purges expired revocations. Verification refuses a matching digest. The API revokes first and clears the cookie only after the database accepts the operation; storage failures must not be reported as a completed logout. Tests in `tests/test_api_auth.py` cover copied cookie replay across TestClient restarts, isolation from another session, and digest-only persistence. No running repository auth/Postgres test yet. Rollback to an older application requires rotating `OFFSETX_SESSION_SECRET` first, because old code ignores revocations.
