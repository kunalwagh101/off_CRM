# S-06.02.45 — Filter contacts by their category and A/B variant

**Owner:** frontend/CRM engineer. **Branch:** develop. **Status:** IN_REVIEW.

## Acceptance
- Category and variant dropdown choices come from real campaign membership values, not guesses or a hardcoded list; the campaign must exist before facets are returned.
- Both filters can be combined with existing server-backed search/status/pagination. Filtering resets to page 1, counts remain server-derived and no other campaign is used.
- An operator can clear either filter individually. No campaign data is sent to a model.
- Existing API fields `category` and `variant_id` remain exact-match; URL values are safely encoded. The new facet endpoint is protected by the existing API authentication middleware.
