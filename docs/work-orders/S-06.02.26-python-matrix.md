## GOAL
The suite runs on Python 3.10, 3.11 and 3.12 on every push — the versions
`pyproject.toml` declares, and the one the Docker image runs — and a version
added in one place but not the other fails a test.

## BLAST RADIUS / CONSUMERS
- `.github/workflows/ci.yml` — one job, `quality`, on `python-version: "3.12"`.
  It installs with `uv sync --extra dev --extra email --locked`, runs the suite,
  builds the frontend and re-runs the board verifier's evidence.
- `pyproject.toml` — `requires-python = ">=3.10"`, classifiers for 3.10, 3.11
  and 3.12.
- `Dockerfile` — `FROM python:3.12-slim`.
- `uv.lock` — resolves for all three; on 2026-09-23 a real 3.10 environment was
  built from it with `--locked` and the whole suite passed there (2,371 tests).

## ROOT CAUSE
CI tests one version; local work used 3.11; the image runs 3.12. Nothing ran
3.10, which the package says it supports, so `asyncio.timeout` (3.11+) broke
every backup there, and `tomllib` (3.11+) stopped the suite loading, unseen.

## DESIGN
- Split `ci.yml` into two jobs. `suite`: a matrix
  `python-version: ["3.10", "3.11", "3.12"]` that installs from the lock and runs
  `uv run pytest -q`. `quality`: one version (3.12, the image's), with the
  frontend build and the board verifier — they do not depend on the Python
  version, and running them three times triples the minutes for nothing.
- Tell uv which interpreter to use: `uv sync --python ${{ matrix.python-version }} …`.
- Keep `fetch-depth: 0` in whichever job runs the verifier (the reason is in
  the comment already in the file).

## TEST (write it first — it runs without CI)
`tests/test_supported_pythons.py` reads three files and compares sets:
- the `Programming Language :: Python :: 3.x` classifiers in `pyproject.toml`
  (read with `tomllib`, falling back to `tomli` on 3.10 — the pattern is in
  `tests/test_ai_registry_packaging.py`);
- the `FROM python:3.x` version in `Dockerfile`;
- the `python-version` matrix in `.github/workflows/ci.yml` (read with PyYAML).

It asserts that every classifier version and the Dockerfile version are in the
matrix. It fails today (the matrix does not exist) and passes after the change.
